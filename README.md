# Ekoli Chemie Escape Room

This folder contains a local adaptation of the Ekoli Chemie Escape Room project from the original GitHub repository.

## Purpose

The project is a browser-based escape-room experience with HTML, CSS, and media assets. This repository is prepared for GitHub hosting and for submitting a pull request back to the upstream project.

## Usage

Open [admin.html](admin.html) or [player.html](player.html) in a browser to explore the experience.
